  1. Create an internal Slack app at api.slack.com/apps in the Azumuta workspace.
  2. Under OAuth & Permissions → User Token Scopes, add search:read.public, search:read.private, search:read.im, search:read.mpim, search:read.users, search:read.files.
  3. Install to the workspace and copy the User OAuth Token (xoxp-…).
  4. Put it in poc/slack-realtime/.env as SLACK_USER_TOKEN, then restart this server.
