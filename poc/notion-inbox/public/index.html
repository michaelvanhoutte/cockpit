Notion follow-up inbox — proof of concept

Can the public Notion API give Cockpit the four things that belong in a follow-up inbox — assignments, document mentions, comment mentions and replies to my comments — and can it tell us when one of them has been handled?

Not configured yet

  1. Create an internal integration at notion.so/profile/integrations in your own workspace.
  2. Under Capabilities, enable Read content, Read comments and Read user information including email addresses. The last one is how the harness works out which user id is you.
  3. Copy the Internal Integration Secret (ntn_…) into poc/notion-inbox/.env as NOTION_TOKEN, and set NOTION_PERSON_EMAIL to your Notion account email.
  4. Share content with it: open a page, ··· → Connections → add the integration. Subpages inherit access, so connecting near the top of a teamspace usually covers everything. An integration starts with access to nothing, which is the single most common reason a run comes back empty.
  5. Restart this server.
